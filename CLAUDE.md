# Scale Shift: notes for Claude Code

True-size world map with a timeline from 1 BC to today. Next.js 16 (App Router, Cache Components on), TypeScript, Tailwind 4, d3-geo. No map tiles or API keys.

## Read first
- This is Next.js 16. APIs differ from older versions: check `node_modules/next/dist/docs/` before using a Next API you're unsure of.
- `params` is a Promise. `dynamicParams` and similar segment configs are not allowed with Cache Components.
- Dynamic pages (`app/compare/[slug]`, `app/history/[id]`) wrap their content in `<Suspense>` so navigation stays instant. Keep that pattern.

## Where things live
- `content/*.ts`: all copy, comparison pages, featured empires, lineage. Change words here, not in components.
- `lib/geo.ts`: true-size math. `relocate()` rotates shapes on the sphere. Never shift shapes in flat pixels.
- `components/map/*`: the map app (MapApp orchestrates; MapCanvas draws; OverlayPanel, TimeDock, SearchBox).
- `public/data/`: generated by `npm run data` from `data-src/` (not committed). Don't hand-edit. Name aliases live at the top of `scripts/build-data.mjs`.
- `app/api/submit/route.ts`: form endpoint (local JSON file, optional webhook or Resend email).

## Commands
- `npm run dev`: local site at http://localhost:3000
- `npm run lint && npm run typecheck && npm run build`: must all pass before a PR
- `npm run check:data`: after any data change
- `npm run test:e2e`: browser tests (needs `npm run start` running and `npx playwright install chromium` once)

## Rules
- Work on a branch and open a pull request. Never push to `main` directly.
- Entity ids are slugs from `public/data/index.json`; years are snapshot years (`-1` = 1 BC, `2026` = today).
- Historical data is GPL-3.0 (historical-basemaps). Keep the credits in the footer and on /about.
- Antarctica is excluded on purpose: Mercator can't draw a shape that surrounds a pole.
